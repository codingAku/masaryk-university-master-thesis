Full MVR will be present as a separate screen (next to Calculate), with functionality that is only available to the AnalyticalExpert.

## Workflows
The main goal for Full MVR is to build knowledge for the MVR calculation, including: sample selection, curve/segment creation, curve degree testing, and interference testing and selection. Specialists also use Full MVR to build QA knowledge, though QA curves are usually not interfered with. The following two main scenarios are covered by Full MVR:

### Curve from Scratch
- Select a component in the Quality of interest (no existing curve).
- Start with a "raw" curve:
  - Change the selection of samples to be used for that curve; initially, all samples are selected, but the user can limit that set (includes setting sample weights).
  - On the Interferents tab, do not select interferents, but press "Calculate" (consider having this button also on the first tab).
  - Evaluate curve behavior.
  - Keep adding/removing samples until satisfied.
  - Save the curve as "raw."
- Follow up with corrected curves:
  - Move to the Interferents tab.
  - Select additive and/or multiplicative interferents.
  - Press the "validate" button to view scores on the Validation tab.
  - Based on "sign," "CV," "flip/flop," etc., determine interferents to add/remove.
  - Optionally, change the selection of samples.
  - Save the curve with interferents as "save as new curve."

### Update Curve
- Select a quality, component, and existing curve to be corrected.
- Press "Validate" on the Interferents tab.
- Update curve settings based on results from the Validation tab.
- When satisfied, save the curve:
  - Overwrite the existing one ("update") or
  - Save as a new curve ("save as new curve").

> **Note from Sandra Delahaye:** Currently, updating a curve directly isn't possible; modified segments are saved under new names and rearranged manually in "CARL OE > Instrument > Analytical > Mod-Know."

## Ergonomics
Ergonomics is crucial; no data (e.g., curves under development) is saved to the database until explicitly decided by the Expert. Navigation to another quality/component/curve discards unsaved changes.

### Numerical and Graphical tabs
- Numerical results and coefficients overview (save button present).
- Graphical representation of results (save button present).

### Validation tab
- Results erased upon any change on other tabs.
- Includes "Synthesis" summary table and detailed combinations table.
- Tooltips for "CV%," "Error," "r²," and "Flip/Flop" definitions.

> **Discussion:** Clarify "flip/flop" usage with Sandra Delahaye.

### Computation & Validation
- Computation triggered via "MVR" button from Interferences tab.
- Numerical/Graphical tabs show computed results.
- "Validate" button calculates interference effectiveness (summary and combinations detailed on Validation tab).
