Full MVR

Full MVR is presented on a separate screen next to Calculate, accessible only to the AnalyticalExpert.

Workflows

The primary objective of Full MVR is to develop knowledge for MVR calculations, including sample selection, curve and segment creation, curve degree testing, and interference testing and selection. Specialists also use Full MVR to build QA knowledge, though QA curves typically do not involve interferents. The following main scenarios are covered by Full MVR:

Curve from Scratch
Select a component in the Quality of interest (no existing curve).
Begin with a "raw" curve:
- Initially, all samples are selected, but the user can modify this selection and set sample weights.
- On the Interferents tab, initially, do not select interferents. Press "Calculate" (consider availability on the first tab).
- Evaluate curve behavior.
- Adjust sample selection until satisfied.
- Save the curve as "raw."

Creating corrected curves:
- Move to the Interferents tab.
- Select additive and/or multiplicative interferents.
- Press "Validate" to view scores on the Validation tab.
- Determine interferents to add/remove based on metrics such as "sign," "CV," "flip/flop," etc.
- Optionally adjust sample selection.
- Save the curve with interferents as "save as new curve."

Update Curve
- Select the quality, component, and existing curve for correction.
- Press "Validate" on the Interferents tab.
- Adjust curve settings based on validation results.
- Save the curve:
  - Overwrite existing ("update"), or
  - Save as new ("save as new curve").

Note from Sandra Delahaye:
Currently, direct curve updates are not possible; modified segments must be saved under new names and rearranged manually in "CARL OE > Instrument > Analytical > Mod-Know."

Ergonomics
Ergonomics are critical. Data is not saved to the database until explicitly decided by the expert. Navigating away from a quality/component/curve will discard unsaved changes.

Requirements

Setup of Full MVR
- Full MVR appears on a separate screen, accessible by AnalyticalExpert only, alongside the Compute screen.
- Full MVR contains the following tabs: Curves, Interferences, Validation, Numerical, Graphical.
- Each tab displays the matrix, quality, component, and curve. Instrument family and number are indicated at the top-left.
- Saving a curve requires entering a segment name and an optional remark. Data is stored in Toucan.

Curves Tab
- Quality selection available via dropdown (name, Base-Element, Version).
- QuickSwitch instrument button for rapid selection of another OES/XR instrument.
- Users can type an instrument number directly.
- Components are listed by name, displaying Name, Element, and Internal Standard.
- Available curves are listed with segment name and remarks; a "no curve" option is also available.
- Samples are shown with selection status, name, weight, quality, intensity, sigma, concentration, accuracy, and certification status (color-coded).
- Sample data populates based on imported information, ignoring QA "Repro" measurements.
- Selection/deselection of samples can be based on metallurgical qualities.
- Concentration filters dynamically update sample selections.
- Weight settings include: "all 1," "f(Concentration)," and "1 / Intensity."
- CSV export of samples is handled via the backend.

Interferences Tab
- Lists BaseElements for selecting additive/multiplicative interferents.
- Interference details include selection, concentration range (min/max), and sample count.
- "MVR" button computes the curve based on settings, automatically opening the Numerical tab.
- Curve degree can be specified (0-3).
- ITF validation degree options: free (default), 1, 2, or 3.
- No save button; validation is required first.

Numerical and Graphical Tabs
- Display numerical results and coefficients with save options.
- Graphical tab visually represents results with save options.

Validation Tab
- Results clear upon changes in other tabs.
- Includes a "Synthesis" summary table and detailed combinations.
- Tooltips explain "CV%," "Error," "r²," and "Flip/Flop."

Computation & Validation
- Computation via the "MVR" button on the Interferences tab.
- Numerical and Graphical tabs show computed results.
- "Validate" calculates interference effectiveness, displayed on the Validation tab.

Implementation Notes:
- Two-step saving process: available only on Numerical and Graphical tabs.
- Interference coefficients are auto-computed.
- CSV export functionality is managed by the backend.

UI Ergonomics:
- Minimize clicks, clearly indicate unsaved states, and enable quick testing.

This structured approach ensures clarity and ease of use for experts conducting complex curve analyses in Full MVR.
